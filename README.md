# Jogo da Velha com IA 🎮

Um projeto simples de **Jogo da Velha (Tic-Tac-Toe)** desenvolvido em **HTML, CSS e JavaScript**, com uma **IA básica** para jogar contra o usuário.

## ✨ Funcionalidades
- Tabuleiro interativo em 3x3
- Alternância entre jogador humano (X) e computador (O)
- Verificação automática de vitória ou empate
- Reinício rápido da partida
- IA simples:
  - Tenta vencer se possível
  - Bloqueia jogadas do jogador
  - Caso contrário, escolhe uma célula aleatória

## 🚀 Tecnologias utilizadas
- **[HTML](ca://s?q=Aprender_HTML_basico)** para estrutura
- **[CSS](ca://s?q=Aprender_CSS_basico)** para estilização
- **[JavaScript](ca://s?q=Aprender_JavaScript_basico)** para lógica do jogo e da IA
